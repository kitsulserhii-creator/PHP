## Технічна реалізація

### Структура бази даних

#### Таблиця `categories`
```sql
CREATE TABLE categories (
    id INT AUTO_INCREMENT PRIMARY KEY,
    name VARCHAR(100) NOT NULL UNIQUE,
    description TEXT,
    INDEX idx_name (name)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci;
```

#### Таблиця `comments`
```sql
CREATE TABLE comments (
    id INT AUTO_INCREMENT PRIMARY KEY,
    automobile_id INT NOT NULL,
    user_id INT NOT NULL,
    comment_text TEXT NOT NULL,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    FOREIGN KEY (automobile_id) REFERENCES automobiles(id) ON DELETE CASCADE,
    FOREIGN KEY (user_id) REFERENCES users(id) ON DELETE CASCADE,
    INDEX idx_automobile (automobile_id),
    INDEX idx_created (created_at)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci;
```

#### Модифікація таблиці `automobiles`
```sql
ALTER TABLE automobiles 
ADD COLUMN category_id INT NULL,
ADD FOREIGN KEY (category_id) REFERENCES categories(id) ON DELETE SET NULL;
```

## Функціональність

### Система коментарів (Варіант 1)

#### Додавання коментаря
1. Увійдіть на сайт (admin / Password123 або user1 / Password123)
2. Перейдіть на сторінку перегляду будь-якого автомобіля
3. Прокрутіть донизу до секції "Коментарі"
4. Введіть текст коментаря (мінімум 3 символи)
5. Натисніть "Додати коментар"

**Бізнес-логіка:**
- Додавати коментарі можуть лише авторизовані користувачі
- Гості бачать повідомлення "Щоб залишити коментар, потрібно увійти"
- Коментарі відображаються у порядку від найновіших до найстаріших
- Кожен коментар показує автора, дату створення та текст

#### Видалення коментаря (тільки адміністратор)
1. Увійдіть як адміністратор (admin / Password123)
2. Відкрийте сторінку автомобіля з коментарями
3. Біля кожного коментаря є кнопка "Видалити" (іконка корзини)
4. Натисніть кнопку — коментар буде видалено після підтвердження JavaScript

**Захист:**
- CSRF токен перевіряється на сервері
- Перевірка адміністративних прав перед видаленням
- SQL injection захист через PDO prepared statements
- XSS захист через `htmlspecialchars()` на виводі

### Категорії автомобілів (Варіант 5)

#### Управління категоріями (тільки адміністратор)
1. Увійдіть як адміністратор (admin / Password123)
2. У лівому меню натисніть **"Категорії"** (у секції АДМІН)
3. Сторінка розділена на дві частини:
   - Ліворуч: форма додавання нової категорії
   - Праворуч: таблиця існуючих категорій

**Додавання категорії:**
- Введіть назву категорії (обов'язково, максимум 100 символів)
- Введіть опис категорії (опціонально)
- Натисніть "Додати категорію"
- Назва категорії має бути унікальною

**Видалення категорії:**
- У таблиці категорій натисніть "Видалити" біля потрібної категорії
- Підтвердіть видалення у спливаючому вікні JavaScript
- Якщо категорія використовується в автомобілях, вона буде видалена, а в полі `category_id` у автомобілів встановиться `NULL`

**Відображення інформації:**
- Таблиця показує ID, назву, опис та кількість автомобілів у кожній категорії
- Кількість автомобілів оновлюється автоматично через SQL JOIN

#### Призначення категорії автомобілю
1. Перейдіть на сторінку створення або редагування автомобіля
2. Знайдіть випадний список "Категорія" (між полями "Колір" та "Ціна")
3. Виберіть категорію зі списку або залиште "-- Не вибрано --"
4. Збережіть автомобіль

**Особливості:**
- Категорія є опціональною — можна залишити автомобіль без категорії
- Якщо категорію видалено, автомобіль залишається без категорії (не видаляється)
- Категорії сортуються в алфавітному порядку

#### Перегляд автомобілів за категорією
1. Відкрийте сторінку списку автомобілів (Автомобілі)
2. У лівій бічній панелі відображається список категорій
3. Натисніть на назву категорії — відкриється сторінка з автомобілями цієї категорії
4. На сторінці категорії показується:
   - Назва категорії
   - Опис категорії
   - Список автомобілів у вигляді карток
   - Загальна кількість автомобілів

**Фільтрація за ролями:**
- Адміністратор бачить усі автомобілі (опубліковані та неопубліковані)
- Звичайні користувачі та гості бачать лише опубліковані (`visible = 1`)

#### Відображення категорії на сторінках
- **Список автомобілів:** категорія відображається в деталях картки як посилання
- **Сторінка перегляду:** категорія відображається у таблиці інформації
- **Кнопка "Всі категорії"** у бічній панелі повертає до повного списку

## Безпека

### Застосовані заходи захисту

#### SQL Injection
- Усі запити до БД використовують PDO Prepared Statements
- Параметри передаються через масив окремо від SQL-рядка
- `(int)` casting для числових ID із `$_GET` та `$_POST`

#### XSS (Cross-Site Scripting)
- Усі дані користувача обробляються через `htmlspecialchars()` перед виводом
- Використання прапорців `ENT_QUOTES | ENT_SUBSTITUTE` та `'UTF-8'`
- Текст коментарів виводиться через `nl2br()` для збереження переносів рядків

#### CSRF (Cross-Site Request Forgery)
- Кожна форма (додавання коментаря, створення категорії) містить CSRF токен
- Токен генерується криптографічно безпечно: `bin2hex(random_bytes(32))`
- Токен перевіряється на сервері перед обробкою POST-запиту
- Невалідний токен = відхилення запиту з повідомленням про помилку

#### Авторизація та права доступу
- Видалення коментарів доступне лише адміністраторам (`$_SESSION['user_admin']`)
- Управління категоріями доступне лише адміністраторам
- Незалогінені користувачі не можуть додавати коментарі
- Перевірка прав відбувається на сервері (не лише у UI)

#### Валідація даних
- Коментар: мінімум 3 символи, максимум 5000 символів
- Назва категорії: обов'язкове поле, максимум 100 символів, унікальна
- Опис категорії: опціонально, максимум 1000 символів
- Усі текстові поля очищуються через `trim()`
