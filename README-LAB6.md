### 1. Створення таблиці automobiles (1 бал)

**Структура таблиці**:
```sql
CREATE TABLE automobiles (
    id INT UNSIGNED AUTO_INCREMENT PRIMARY KEY,
    brand VARCHAR(100) NOT NULL,              -- Марка
    model VARCHAR(100) NOT NULL,              -- Модель
    year YEAR NOT NULL,                       -- Рік випуску
    color VARCHAR(50),                        -- Колір (опціонально)
    price DECIMAL(10,2),                      -- Ціна в USD (опціонально)
    mileage INT UNSIGNED,                     -- Пробіг в км (опціонально)
    description TEXT,                         -- Опис (опціонально)
    visible TINYINT(1) NOT NULL DEFAULT 0,    -- 1 = опублікований, 0 = ні
    date TIMESTAMP DEFAULT CURRENT_TIMESTAMP, -- Дата додавання (автоматично)
    author_id INT UNSIGNED NOT NULL,          -- FK -> users.id
    FOREIGN KEY (author_id) REFERENCES users(id) ON DELETE CASCADE
);
```

**Обов'язкові поля згідно завдання**:
- ✅ `visible` (TINYINT 1/0) - статус публікації
- ✅ `date` (TIMESTAMP, CURRENT_TIMESTAMP) - дата додавання (автоматично)
- ✅ `author_id` (INT UNSIGNED, FK) - зовнішній ключ на users.id

**Індекси** для продуктивності:
- `idx_visible` - швидкий пошук опублікованих
- `idx_date` - сортування за датою
- `idx_author` - пошук за автором

## Безпека - MAX рівень 🔒

### Реалізовані заходи:

1. **SQL Injection**:
   - PDO підготовлені запити для всіх запитів
   - `(int)$_GET['id']` для числових параметрів
   - `EMULATE_PREPARES = false` (справжні prepared statements)

2. **XSS**:
   - `htmlspecialchars()` з `ENT_QUOTES | ENT_SUBSTITUTE, 'UTF-8'` на всіх виведеннях
   - `nl2br()` тільки після escaping

3. **CSRF**:
   - Токен `bin2hex(random_bytes(32))` на всіх POST формах
   - Перевірка через `hash_equals()` (захист від timing attacks)
   - Регенерація токена після операцій

4. **Authorization**:
   - Перевірка `$_SESSION['user_logged']` перед CRUD операціями
   - Перевірка `$_SESSION['user_admin']` для адміністративних функцій
   - Редирект якщо немає доступу

5. **Data Validation**:
   - Всі поля валідуються на сервері (не тільки браузером)
   - Whitelist підхід - приймаються тільки відомі значення
   - Типізація через `(int)`, `(float)`, `trim()`
   - Регулярні вирази для форматів

6. **Foreign Key Constraint**:
   - `ON DELETE CASCADE` - автоматичне видалення автомобілів при видаленні користувача
   - Унеможливлює orphaned records

7. **Error Handling**:
   - Помилки БД логуються через `error_log()`
   - Користувачу показується загальне повідомлення (не деталі)

8. **JavaScript Confirmation**:
   - `confirm()` перед видаленням з назвою автомобіля
   - `return false` якщо користувач скасував
