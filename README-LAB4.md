# Лабораторна робота №4: Підключення до бази даних MySQL

## Виконані завдання ✅

### 1. Створена база даних MySQL (2 бали)
- **Назва бази даних**: `phpp_portfolio`
- **Кодування**: `utf8mb4` (підтримка всіх Unicode символів, включаючи емодзі)
- **Collation**: `utf8mb4_unicode_ci`
- **Місце створення**: XAMPP/phpMyAdmin

### 2. Створена таблиця `users` (2 бали)
Таблиця містить всі необхідні поля:
- `id` - первинний ключ (INT UNSIGNED AUTO_INCREMENT)
- `login` - логін користувача (VARCHAR 255, UNIQUE)
- `password_hash` - хеш пароля (VARCHAR 255)
- `email` - електронна пошта (VARCHAR 255)
- `admin` - тип користувача (TINYINT: 1 = адмін, 0 = звичайний)
- `name` - ім'я (VARCHAR 255, опціонально)
- `about` - про себе (TEXT, опціонально)
- `gender` - стать (TINYINT: 0 = жіноча, 1 = чоловіча)
- `phone` - телефон (VARCHAR 30, опціонально)
- `dob` - дата народження (VARCHAR 50)
- `created_at` - дата створення (TIMESTAMP, автоматично)
- `updated_at` - дата оновлення (TIMESTAMP, автоматично)

**Індекси**:
- PRIMARY KEY на `id`
- INDEX на `login` для швидкого пошуку
- INDEX на `email`

### 3. Додано код реєстрації в таблицю `users` (4 бали)
- Створено `config/database.php` з функціями для роботи з БД
- Використовується PDO з підготовленими запитами (захист від SQL-ін'єкцій)
- Конфігурація:
  - `PDO::ERRMODE_EXCEPTION` - виключення при помилках
  - `PDO::EMULATE_PREPARES = false` - справжні підготовлені запити
  - `PDO::FETCH_ASSOC` - асоціативні масиви

### 4. Використання функції password_hash (2 бали)
- Алгоритм: `PASSWORD_BCRYPT`
- Cost factor: 12 (балан між безпекою та продуктивністю)
- Функція `password_verify()` для перевірки при вході
