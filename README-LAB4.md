# Лабораторна робота №4: Підключення до бази даних MySQL

## Виконані завдання ✅

### 1. Створена база даних MySQL (2 бали)
- **Назва бази даних**: `phpp_portfolio`
- **Кодування**: `utf8mb4` (підтримка всіх Unicode символів, включаючи емодзі)
- **Collation**: `utf8mb4_unicode_ci`
- **Місце створення**: XAMPP/phpMyAdmin

### 2. Створена таблиця `users` (2 бали)
Таблиця містить всі необхідні поля:
- `id` - первинний ключ (INT UNSIGNED AUTO_INCREMENT)
- `login` - логін користувача (VARCHAR 255, UNIQUE)
- `password_hash` - хеш пароля (VARCHAR 255)
- `email` - електронна пошта (VARCHAR 255)
- `admin` - тип користувача (TINYINT: 1 = адмін, 0 = звичайний)
- `name` - ім'я (VARCHAR 255, опціонально)
- `about` - про себе (TEXT, опціонально)
- `gender` - стать (TINYINT: 0 = жіноча, 1 = чоловіча)
- `phone` - телефон (VARCHAR 30, опціонально)
- `dob` - дата народження (VARCHAR 50)
- `created_at` - дата створення (TIMESTAMP, автоматично)
- `updated_at` - дата оновлення (TIMESTAMP, автоматично)

**Індекси**:
- PRIMARY KEY на `id`
- INDEX на `login` для швидкого пошуку
- INDEX на `email`

### 3. Додано код реєстрації в таблицю `users` (4 бали)
- Створено `config/database.php` з функціями для роботи з БД
- Використовується PDO з підготовленими запитами (захист від SQL-ін'єкцій)
- Конфігурація:
  - `PDO::ERRMODE_EXCEPTION` - виключення при помилках
  - `PDO::EMULATE_PREPARES = false` - справжні підготовлені запити
  - `PDO::FETCH_ASSOC` - асоціативні масиви

### 4. Використання функції password_hash (2 бали)
- Алгоритм: `PASSWORD_BCRYPT`
- Cost factor: 12 (балан між безпекою та продуктивністю)
- Функція `password_verify()` для перевірки при вході

## Безпека

### Реалізовані заходи:
1. **PDO з підготовленими запитами** - захист від SQL-ін'єкцій
2. **password_hash() з BCRYPT** - надійне хешування паролів (cost=12)
3. **Конфігурація винесена в окремий файл** - легко змінити для різних середовищ
4. **Помилки логуються, не показуються користувачу** - не розкривають структуру БД
5. **EMULATE_PREPARES = false** - справжні підготовлені запити на рівні MySQL

### Рекомендації для production:
- Змінити `DB_USER` та `DB_PASS` на безпечні значення
- Додати `config/database.php` до `.gitignore`
- Увімкнути HTTPS
- Встановити `display_errors = Off` у php.ini

## Що НЕ МОЖЕ зробити автоматично

❌ **Створити базу даних через phpMyAdmin** - це потрібно зробити вручну
❌ **Змінити пароль MySQL** - використовується стандартний (пустий для root в XAMPP)
❌ **Налаштувати віддалене підключення** - локально через localhost

## Технічні деталі

### Функції для роботи з БД (config/database.php):

```php
getDbConnection()    // Отримати PDO підключення (singleton)
dbQuery($sql, $params)     // Виконати запит з параметрами
dbFetchOne($sql, $params)  // Отримати один рядок
dbFetchAll($sql, $params)  // Отримати всі рядки
```

### Приклад використання:

```php
// Підключити конфігурацію
require_once __DIR__ . '/config/database.php';

// Знайти користувача
$user = dbFetchOne(
    "SELECT * FROM users WHERE login = ? LIMIT 1",
    [$login]
);

// Перевірити пароль
if ($user && password_verify($password, $user['password_hash'])) {
    // Успішний вхід
}
```
